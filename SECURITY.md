# Security policy

## Supported versions

Until Flash reaches 1.0, security fixes are provided for the latest released
minor version only.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older versions | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting on the repository's **Security** tab and
include:

- the affected Flash version and Linux distribution;
- a minimal reproducer or malicious byte stream when safe to share;
- the expected and observed behavior;
- the likely impact; and
- any suggested mitigation.

You should receive an acknowledgement within seven days. If the report is
confirmed, maintainers will coordinate a fix and disclosure with the reporter.
Never include secrets, real shell history, or personal clipboard contents in a
report.
